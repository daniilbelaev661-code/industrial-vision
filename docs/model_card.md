# Model Card: Детекторы для системы технического зрения

## 1. Общая информация
В рамках проекта обучены и интегрированы две специализированные модели детекции на базе архитектуры **YOLOv8n**:
1. **PPE Detector** — контроль средств индивидуальной защиты (СИЗ).
2. **Smoke/Fire Detector** — обнаружение дыма и огня.

Обе модели используются в едином конвейере вместе с базовой моделью `yolov8n.pt` (для трекинга людей).

---

## 2. Модель 1: PPE Detector (Контроль СИЗ)

*   **Архитектура:** YOLOv8n (Ultralytics)
*   **Задача:** Object Detection (Детекция объектов)
*   **Вход:** RGB-изображение 640x640 (нормализованное)
*   **Данные:** Датасет PPE Detection (Roboflow Universe, проект `testcasque/ppe-detection-qlq3d`, лицензия CC BY 4.0). Подробнее в `docs/dataset_card.md`.
*   **Обучение:**
    *   Базовая модель: `yolov8n.pt`
    *   Эпохи: 80 (из 150 запланированных, сработала ранняя остановка при `patience=20`).
    *   Batch size: 16
    *   Оптимизатор: AdamW (по умолчанию в Ultralytics)
    *   Augmentation: стандартные аугментации Ultralytics (mosaic, mixup и др.).
    *   Обучение проводилось на GPU NVIDIA RTX 5060 Ti (16 ГБ).
*   **Метрики (на валидационной выборке):**
    *   **mAP@50:** 0.641 (64.1%)
    *   **Precision:** 0.634 (63.4%)
    *   **Recall:** 0.920 (92.0%) 
    *   По классам: `helmet` (mAP50: 0.641), `vest` (mAP50: 0.643).
*   **Производительность (Benchmark):**
    *   PyTorch (`.pt`): ~9.85 мс на кадр (101.5 FPS).
    *   ONNX (`.onnx`): ~6.95 мс на кадр (143.8 FPS).
    *   Замеры выполнены на RTX 5060 Ti, разрешение 640.
*   **Ограничения и Known Biases:**
    *   Модель плохо детектирует СИЗ на людях, находящихся на большом удалении (размер объекта менее 120 пикселей по высоте), поэтому в `EventEngine` введен фильтр `min_person_height`.
    *   Возможны ложные срабатывания (FP) на объекты схожего цвета (например, желтые машины могут быть спутаны с жилетом).
    *   Не выявляет отсутствие каски у людей, стоящих спиной к камере, если каска не видна.
*   **Применение в конвейере:** Вызывается для каждого кадра, результаты сопоставляются с рамками людей (`person`) через функцию `check_person_ppe`.

## 3. Модель 2: Smoke/Fire Detector (Дым и Огонь)

*   **Архитектура:** YOLOv8n (Ultralytics)
*   **Задача:** Object Detection
*   **Вход:** RGB-изображение 640x640
*   **Данные:** Датасет Fire & Smoke Detection (Roboflow Universe, проект `mahmoud-9wyf6/fire-smoke-detection`). Классы: `Fire`, `Smoke`.
*   **Обучение:**
    *   Базовая модель: `yolov8n.pt`
    *   Эпохи: 70 (из 100 запланированных, сработала ранняя остановка при `patience=20`).
    *   Batch size: 16
    *   Обучение проводилось на GPU NVIDIA RTX 5060 Ti.
*   **Метрики (на валидационной выборке):**
    *   **mAP@50:** 0.704 (70.4%)
    *   **Precision:** 0.813 (81.3%)
    *   **Recall:** 0.637 (63.7%)
    *   По классам: `Smoke` (mAP50: 0.731), `Fire` (mAP50: 0.677).
*   **Производительность:** Аналогична PPE-модели (инференс < 10 мс на PyTorch).
*   **Ограничения:**
    *   Основная сложность — **Hard Negatives**. Модель может путать густой пар с дымом, а яркие блики солнца или сварку — с огнем.
    *   Для подавления ложных срабатываний в `configuration.yaml` установлен повышенный порог `confidence` (0.60 для дыма и 0.60 для огня) и используется `TemporalConfirm` (N=3, M=5).
*   **Применение в конвейере:** Вызывается параллельно с PPE-моделью. При обнаружении формируется глобальное событие `smoke_detected` или `fire_detected`.
